# data-dev

个人数据开发与编程学习仓库。

## 目录结构

data-dev/
├── notes/cheatsheets   # 学习笔记与速查表
├── sql                 # SQL 练习与脚本
├── shell               # Shell 脚本练习
├── python              # Python 练习文件
├── data                # 数据文件（CSV、SQL 导出等）
├── projects            # 项目文件
├── docs                # 文档
└── README.md           # 本文件

## 使用说明

- 各目录存放对应类型的练习文件
- `data/` 目录下的 CSV 和 SQL 文件已被 `.gitignore` 忽略
- 定期提交更新，保持学习记录

## 技术栈

- SQL
- Shell
- Python
